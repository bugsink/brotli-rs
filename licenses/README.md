# Dependency licenses

This directory contains the license texts shipped with the Rust dependencies
locked by this historical snapshot. The binding itself is licensed under the
root `LICENSE` file. Test-oracle provenance and licensing are recorded under
`tests/upstream/`.

The published `alloc-stdlib` crates declare BSD-3-Clause but omit the license
file. Their directory here reproduces the license from the matching
`alloc-no-stdlib` release in the same upstream project.
