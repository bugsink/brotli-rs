Copied from `python/tests`: `_test_utils.py`, `compress_test.py`,
`compressor_test.py`, `decompress_test.py`, and `decompressor_test.py`.
The files were renamed to pytest's `test_*.py` convention. Their only semantic
adaptation is importing `brotli_rs as brotli`; `_test_utils.py` points at the
local snapshot of the corpus.

`testdata/` is a byte-for-byte copy of `tests/testdata`, except for
`bb.binast`. That 12 MB source file has no matching `.compressed` vector and is
not selected by the Python tests, so including it would not increase coverage.

`synth_test.go` is a byte-for-byte copy of `go/brotli/synth_test.go`.
`test_synth_vectors.py` parses its generated byte arrays and expected outputs,
then runs the 45 enabled cases through brotli-rs. It preserves Google's one
explicitly skipped case as skipped. Keeping the original generated file makes
both the upstream test names and vector bytes directly auditable.
