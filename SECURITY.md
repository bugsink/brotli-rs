# Security Policy

Please report vulnerabilities using [GitHub private vulnerability
reporting](https://github.com/bugsink/brotli-rs/security/advisories/new), which
is [documented
here](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability),
or privately at security@bugsink.com.
